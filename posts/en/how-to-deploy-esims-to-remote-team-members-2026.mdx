## Step 3: Guide Employees Through eSIM Installation

Once purchased, employees receive an email containing a QR code and installation instructions. Most can self-activate with minimal IT support.

### Standard Installation Steps (iOS and Android)

**For iPhone (iOS 14+):**

1. Open email on a different device or print the QR code
2. On the iPhone, go to **Settings > Cellular > Add eSIM**
3. Select **Use QR Code**
4. Point camera at QR code
5. Follow prompts to complete installation
6. Label the new line (e.g., "Work - Nexitel")

**For Android (varies by manufacturer):**

1. Open email on another device or save QR code image
2. Go to **Settings > Network & Internet > SIMs > Add SIM**
3. Select **Download a SIM instead?** or **Add eSIM**
4. Scan QR code or enter details manually
5. Complete setup and label the line

**Dual SIM configuration tips:**
- Set the work eSIM as "Cellular Data" if most internet usage is work-related
- Keep personal SIM for personal calls/texts
- Configure "Default Voice Line" based on team preference
- Use contact groups to route specific calls through the work number

## Step 4: Set Up Calling Labels and Number Management

After activation, each line receives a new US phone number. This number is assigned during the eSIM activation process and displayed in the device's cellular settings.

**Collecting and tracking numbers:**

Have each employee confirm their assigned number by checking:
- **iPhone:** Settings > Cellular > [Line Name] — number appears at top
- **Android:** Settings > Network & Internet > SIMs > [eSIM Name] — number listed

Create an internal directory:
- Employee name
- Department/role
- Nexitel assigned number
- Plan type
- Activation date
- Renewal date (30 days from activation)

Distribute this directory so team members can reach each other on work lines.

For most team members, centralized admin renewal ensures no service lapses. For employees who need flexibility (e.g., taking a month off), allow them to skip renewal and reactivate when needed.

## Step 6: Handle Common Deployment Scenarios

### New Hire Onboarding

Include eSIM activation in the IT onboarding checklist:
- Purchase plan on hire date
- Send QR code to work email
- Schedule 15-minute setup call if employee needs assistance
- Add to internal directory once number is confirmed

### Employee Offboarding

When an employee leaves:
- Stop renewing their line at the next expiration
- Line automatically deactivates after 30 days
- Number is released back to the carrier
- Remove from internal directory

No cancellation process is required — simply discontinue renewals.

### Lost Device or QR Code

If an employee loses their device before activating:
- Original QR code remains valid until used
- If QR code email was deleted, contact Nexitel support via website chat
- Support can resend the activation QR to the original purchase email

If device is lost after activation:
- The eSIM is tied to that specific device
- Purchase a new plan for the replacement device
- The old line will expire at the next renewal cycle if not recharged

### Switching Between Network Types

Nexitel Blue (AT&T) and Purple (T-Mobile) plans operate on different networks. If coverage is inadequate:

You cannot transfer a number between networks. Instead:
1. Purchase a new plan on the other network ([nexitel.us/activate](https://www.nexitel.us/activate))
2. Employee receives a new US number
3. Update internal directory
4. Let the original line expire by not renewing

Plan changes within the same network family (Blue to Blue, or Purple to Purple) also require a new activation and new number assignment.

## Security and Policy Considerations

**Work vs. Personal Use:**

Since Nexitel provides a full phone line (not just data), establish clear usage policies:
- Is the work line exclusively for business communication?
- Can employees share the number with family for emergencies?
- What happens to the number after employment ends?

**Data Security:**

eSIM connections use the same cellular network security as physical SIMs. For sensitive communications:
- Encourage use of end-to-end encrypted apps (Signal, WhatsApp) for confidential discussions
- Remind employees that standard SMS is not encrypted
- Consider a separate VPN for data traffic if company policy requires

**Compliance and Record Keeping:**

For regulated industries:
- Keep records of which employee used which number during what time period
- Retain activation and renewal receipts for auditing
- Be aware that call detail records (CDRs) are available from Nexitel support if needed for compliance

## Troubleshooting Common Issues

**QR code won't scan:**
- Ensure brightness is turned up on the display showing the QR
- Try printing the QR code if screen reflection is an issue
- Use the manual entry option (details in activation email)

**eSIM activation fails:**
- Confirm device is eSIM-compatible (most 2020+ iPhones and 2022+ Android flagships)
- Check that device is not carrier-locked to another provider
- Verify active internet connection (Wi-Fi or existing cellular data)

**Coverage issues after activation:**
- Confirm whether employee has Blue (AT&T) or Purple (T-Mobile)
- Check coverage maps: Blue network at att.com/maps, Purple network at t-mobile.com/coverage
- If coverage is inadequate, purchase a plan on the other network

**Number not appearing in directory:**
- Ask employee to check Settings > Cellular/Network settings for the assigned number
- It's listed at the top of the eSIM line's detail page

## Scaling Beyond Your First Deployment

As you grow from 10 to 50 to 100+ remote lines, consider:

**Automation:**
- Use a spreadsheet or simple database to track renewal dates
- Set calendar reminders 5 days before each line's renewal
- Some teams use expense management software to track per-employee telecom costs

**Tiered Plans:**
- Create standard package tiers (e.g., "Support Tier", "Sales Tier", "Executive Tier")
- Map each role to a tier
- New hires automatically get the plan matching their role tier

**Pilot New Plans:**
- When new team members join, test both network families if unsure
- After 30 days, ask which network performed better
- Standardize future hires in that region on the winning network

**Seasonal Scaling:**
- For seasonal businesses, activate lines only during busy periods
- Let them expire during off-season
- Reactivate with new numbers when needed again
